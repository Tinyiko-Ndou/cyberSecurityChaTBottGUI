Description
The chatbot interacts with users through a graphical user interface (GUI) and provides cybersecurity tips and guidance.

 Features:
- WPF graphical user interface
- Interactive chatbot responses
- Random cybersecurity tips
- Sentiment detection
- User memory system
- ASCII art welcome banner
- Greeting sound effect
- Topic remembrance functionality
- 
- Steps to clone
1. Clone or download the repository
2. Open the solution in Visual Studio
3. Build the project
4. Run the application
